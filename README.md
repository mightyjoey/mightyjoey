## Selected work

**[Tape Measure Baseball](https://tapemeasurebaseball.com)** — a free browser game
where you watch a batted ball and guess how far it travelled. Spring Boot, React,
PostgreSQL, deployed to a VPS behind Caddy with GitHub Actions CI. Sources and
trims its own clips from a live MLB data pipeline, runs daily and endless game
modes with server-authoritative scoring, and separates database roles so the
running app can't alter its own schema.
